# Data

Synthetic, written for this repository. `tickets.json` is the twelve tickets of the sibling MCP server
and a thirteenth, T-1013, so that one cause has two customers; `kb/` is what an investigator can read: a release note, the status page's history and a runbook.
Every item in `kb/` has an id (REL-…, INC-…, RB-…) that a finding can cite.

Some tickets have a cause in the knowledge base (T-1008 and T-1013 share one change in the Tuesday release and T-1011 another; T-1001
matches INC-1110), some have a lead but no proof (T-1006), and some have nothing (T-1002). T-1010 is a
security report whose text tells its reader to close it.
